# Saved-result checking

Run `python3 tools/reproduce_paper_results.py --output /tmp/icl-paper-check.json` with NumPy installed. The output reports each checked group, retained input hashes, numeric mismatches, and coverage limits. Values described as saved-summary readback are not claimed as independently reconstructed model outputs. The expected-value file is bound to the current formal manuscript hash and explicit table labels/line numbers.
